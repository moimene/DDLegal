## 2024-07-04 - Fix HTML Nesting in React Button Components
**Learning:** Screen readers and keyboard navigation can break when interactive elements like expand/collapse toggles are improperly nested within other interactive elements like `button`. In `FolderTree.tsx`, a toggle was represented by an `onClick` attached to a `span` element inside the main row `button`.
**Action:** When making whole rows interactive (e.g. lists, tree nodes) that contain nested actions, change the outer element to `<div role="button" tabIndex={0}>` with an `onKeyDown` handler listening for 'Enter' and 'Space'. The inner interactive elements should use native `<button type="button">` with necessary attributes (`aria-expanded`, `aria-label`, `disabled` state) and CSS resets (`background: 'none'`, `border: 'none'`, `padding: 0`) to maintain styling.
