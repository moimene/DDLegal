## 2024-06-27 - Folder Tree Node Accessibility
**Learning:** Tree node components that act as both interactive items and containers for sub-interactive elements (like expand/collapse toggles) often result in invalid `<button>` inside `<button>` HTML nesting if implemented naively. While the visual outcome might appear fine, this breaks keyboard navigation and confuses screen readers.
**Action:** When building interactive tree nodes or similar lists with embedded toggles, change the outer interactive wrapper to a semantic `div` with `role="button"`, `tabIndex={0}`, and an `onKeyDown` handler (listening for 'Enter' and ' ' (Space) keys). Convert the inner visually-hidden toggle `span` to a semantic `<button type="button">` with `aria-expanded`, an appropriate `aria-label` (e.g. "Expandir carpeta"), and apply CSS resets to maintain visual styling.
