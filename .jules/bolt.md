## 2024-05-29 - O(N²) Arrays Over Maps
**Learning:** Found a critical performance bottleneck where `Array.prototype.find()` was called inside a loop over the mapped array `scoredFindings`, resulting in an O(N²) time complexity for `calculateDealRiskScore`. Additionally, there were three subsequent redundant loops (e.g. `scoredFindings.filter`, `activeFindingsAll.reduce`). This caused heavy iteration overhead and scaling issues for large datasets.
**Action:** When working on array mappings and groupings, I should always check if the original logic can be consolidated into a single O(N) pass. I resolved this by extracting the relevant grouping operations, tracking totals (`totalEconomicExposure`), and logic dependent on the original array (`f.severity`) into the primary `map` loop.
