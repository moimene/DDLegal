## 2025-03-01 - Consolidating multiple array filter passes into a single loop
**Learning:** In this codebase, it's common to see aggregate calculations built using many repeated `.filter(condition).length` calls on the same source array (e.g., `buildSummaryFromRows` in `src/app/api/findings/route.ts` used ~23 distinct `.filter()` passes). This creates O(M * N) overhead where M is the number of metrics and N is the array length. This architecture-specific pattern scales poorly with large finding sets returned from Supabase.
**Action:** When calculating multiple separate aggregate metrics (like various counts or sums) from the same array, consolidate the logic into a single O(N) loop iteration rather than traversing the array multiple times using separate `.filter().length` or `.reduce()` calls.
