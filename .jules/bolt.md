## 2024-05-27 - O(N^2) lookup in array mapping
**Learning:** Found a performance bottleneck in `src/lib/scoring/deal-risk-score.ts` where we map over an array of `ScoringInput` and then iterate over the result to group by area, while doing a `.find()` on the original array inside the loop to get the `severity` back. This is O(N^2). Since `ScoringInput` already has `severity`, we can extend `ScoredFinding` or just pass `original_severity` in the first pass to make it O(N).
**Action:** When eliminating O(N²) nested lookups (like `.find()`) within loops over mapped arrays, avoid using index-based lookups (`originalArray[i]`) as they are considered unsafe. Instead, extend the mapped object's interface and pass the required properties from the original array during the initial `.map()` pass, or merge the map and grouping loop.
