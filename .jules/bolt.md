## 2024-05-24 - Preserving Order with O(1) Lookups and Combining Iterations
**Learning:** When refactoring O(N^2) array `.find()` operations into O(1) Maps, especially when the original array is ordered (like descending dates), directly using `new Map(arr.map(...))` or `.set()` without checking will cause newer elements to overwrite older ones, resulting in a functional regression. Also, separate `.filter().length` aggregations can be combined into a single pass to save execution time.
**Action:** When creating Maps from ordered arrays, always use `if (!map.has(key)) map.set(key, item);` to preserve the first-matched (highest priority) item. Always look to combine multiple aggregation metrics (like total vs blocked vs pending tasks) into a single iteration pass instead of iterating the entire array multiple times.
