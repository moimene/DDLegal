## 2024-07-06 - Preventing O(N²) Lookups and First-Occurrence Map Logic
**Learning:** When replacing O(N²) nested lookups (`.find()` inside an array loop) with Map-based O(1) lookups to improve performance, DO NOT instantiate the Map using `new Map(array.map(...))` if preserving first-occurrence logic. Doing so causes later elements in the array to overwrite earlier ones, completely breaking the original logic of `.find()`. This is particularly critical when dealing with arrays that are intentionally sorted (like `ORDER BY created_at DESC`).
**Action:** When building O(1) Maps to replace `.find()`, manually iterate over the source array and conditionally set keys only if they do not already exist (`if (!map.has(key)) map.set(key, item)`). This guarantees the Map correctly models the first-occurrence behavior of a `.find()` lookup.
