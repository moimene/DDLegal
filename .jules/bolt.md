## 2024-06-15 - Optimize N+1 and O(N^2) Array operations in dashboard metrics
**Learning:** In highly aggregated API routes (like a dashboard fetch), running nested array `.filter()` and `.find()` operations inside a `.map()` mapping over projects creates massive O(N^2) bottlenecks when the number of tasks or scores is large. Additionally, using `.map()` to build an O(1) Map for latest elements from a DESC array causes functional regressions by overwriting newer elements with older ones.
**Action:** Always refactor nested iterations into separate O(N) passes that pre-build lookup Maps or aggregate objects. When converting an ordered array (e.g., `ORDER BY created_at DESC`) into a Map where you need the latest value per group, do not use `new Map(array.map(...))` because duplicates overwrite earlier entries. Instead, use a loop with `if (!map.has(key)) map.set(key, item)` to guarantee the first (latest) value is preserved.
