## 2024-06-11 - Single-pass array iteration for complex aggregations
**Learning:** Found an O(N²) bottleneck in `calculateDealRiskScore` where a mapped array was being iterated over to group items, and inside that loop, `find()` was called on the original array to lookup a property. This happens when the initial map doesn't carry over all necessary properties, or when multiple separate aggregations (reduce, filter) are run sequentially over the same data.
**Action:** Always consolidate mapping and nested lookups into a single O(N) pass. When iterating over a mapped array to group or score items, either extend the mapped object to include the required properties directly or, better yet, combine the mapping and grouping into one loop over the original array so all properties are immediately accessible without lookups. Also, fold separate `reduce` and `filter` operations into the same pass.
