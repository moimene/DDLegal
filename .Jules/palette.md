## 2024-03-17 - Sidebar Navigation Accessibility Improvement\n**Learning:** The collapsible group elements within the Sidebar components were conditionally unmounted when collapsed, losing the reference for screen readers due to `aria-controls` missing or pointing to elements not present in the DOM.\n**Action:** Use CSS (`display: none` / `flex`) to toggle the visibility of interactive nested items rather than removing them from the DOM, and apply correct `aria-expanded` and `aria-controls` bindings with matching IDs to make custom collapsible panels properly accessible for screen readers.
