## 2024-04-10 - Spanish Localization for ARIA Attributes
**Learning:** When implementing accessibility enhancements like `aria-label` for icon-only buttons, the accessible names must be carefully localized to match the primary language of the application interface, which is Spanish in this repository.
**Action:** Ensure all added `aria-label` and `title` attributes (e.g., "Cerrar comparacion") use appropriate Spanish phrasing to maintain a consistent experience for screen reader users and tooltip viewers.
