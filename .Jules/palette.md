## 2026-05-13 - Added aria-label to ReportCompare.tsx
**Learning:** Adding an aria-label and title attribute to an icon-only button is an essential accessibility feature. While the project had a couple missing, I should make sure that this is applied uniformly throughout the project, rather than individually in a single component.
**Action:** When working on generic components in this repository, ensure all new interactive icons have standard `aria-label` and `title` tags.
